# 🌐 OSD 2025 — Open Source Day Website

This is the official website for **Open Source Day 2025**, a community-driven event celebrating open-source innovation, collaboration, and learning.

The website is built as a **single-page responsive site** with modern animations, smooth scrolling, and an easy-to-navigate design.

---

## 🚀 Features
- 🏠 **Landing Page / Hero Section** with animated stats & call-to-action buttons  
- 📖 **About Section** introducing Open Source Day 2025  
- 🎤 **Speakers Section** highlighting our keynote speakers  
- 🤝 **Sponsors & Partners Section** with logos & hover effects  
- 📩 **Contact / Registration Form** integrated with email  
- 📍 Embedded **Google Map** for venue location  
- 📱 **Responsive Design** (works on desktop, tablet, and mobile)  
- ✨ **Smooth animations** for sections & count-up numbers
